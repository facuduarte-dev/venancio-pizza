# Venancio Pizza

Sitio web responsive para una pizzería artesanal de Paysandú. Presenta la marca,
el menú y el proceso de elaboración mediante una experiencia visual simple y
adaptable a dispositivos móviles.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Uso local

Abrí `index.html` en el navegador o serví la carpeta con un servidor web local.
